Live view of each stage in the AI-driven SDLC workflow.

How this works

  • This page is polling-based, not push-based. It re-checks status.json every 2 seconds and redraws the page. It is not a live push feed.
  • Total Tokens Used reflects the tokens reported by the specialist agent delegated for that stage (captured from that agent's tool-call result). It does not include the full end-to-end token cost of the orchestrator's own reasoning or tool calls outside of delegation. Treat this number as a good-faith measurement of delegated work, not a total token bill.
  • This page also polls pending-question.json. If the orchestrator has an open question, the normal stage view is replaced by a question panel here until you answer it. See the README for how this "question bridge" works.
